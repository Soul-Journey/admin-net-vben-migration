## 已知边界与后续项

1. VForm 3 使用为旧表单 JSON 兼容而锁定的 Element Plus 版本。进入设计器时仍会出现 `el-radio label` 即将废弃的开发警告，不影响当前功能；应在 VForm 升级专项中处理，不能直接修改依赖产物。
2. 全量单元测试存在一条 Vitest 未来兼容提示：`use-sortable.test.ts` 的 `vi.mock` 应提升到模块顶层。当前 347 项测试全部通过，可在测试基础设施升级时处理。
3. 外部依赖功能需要独立测试账号、密钥和环境后再做真实联调。未配置时禁止为了“全通过”发送短信、邮件、支付、LDAP 同步、MQTT 消息或执行系统更新。
4. 旧版 Selenium `UserTest` 依赖旧版 `8888`、固定凭据、验证码和控制台交互，不适合作为新版自动回归。本轮用新版浏览器流程、接口巡检和安全测试替代，后续应建设正式 API 集成测试项目。
